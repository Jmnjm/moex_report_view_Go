# MOEX Report Viewer (Go)

Сервис для просмотра XML-отчётов Московской биржи: человекочитаемый
веб-интерфейс + REST API для других сервисов. Версия на Go —
переписана с исходной версии на Python/FastAPI, архитектура та же.

## Архитектура

Не парсим содержимое отчётов — используем готовую связку XML +
XSLT-стиль от биржи. Стиль для конкретного отчёта определяется из
самого файла (инструкция `<?xml-stylesheet ... ?>`) и кэшируется
локально после первого скачивания. PostgreSQL используется как
реестр метаданных (тип отчёта, путь к файлу, путь к стилю) — не для
хранения самих данных отчётов.

Трансформация XML в HTML выполняется через внешнюю утилиту
`xsltproc` (вызывается из Go как отдельный процесс) — в экосистеме
Go нет зрелой встроенной библиотеки для XSLT, в отличие от Python
(lxml оборачивает libxslt напрямую). Это тот же движок libxslt,
только вызванный явно — подход, который сама биржа рекомендует в
документации.

## Структура проекта

- `db.go` — работа с реестром отчётов в PostgreSQL
- `scan_reports.go` — сканирует reports/, определяет и кэширует стиль для новых файлов
- `xslt_resolver.go` — извлекает ссылку на стиль из XML, скачивает и кэширует
- `transform.go` — XML + XSLT (через xsltproc) → готовый HTML
- `main.go` — веб-сервер: страницы для людей + JSON API

## Требования

- Go 1.22+ (для локального запуска без Docker)
- `xsltproc` установлен в системе (в Docker-образе уже включён)

## Запуск

1. Положить XML-отчёты в `reports/<тип_рынка>/`, например `reports/Currency/`.
2. Поднять сервис:
   ```
   docker compose up --build
   ```
   Дождаться строки: `Uvicorn-аналог запущен на http://0.0.0.0:8000`
3. Открыть `http://localhost:8000/` (не `0.0.0.0`) — список отчётов.
4. Сканирование новых файлов сейчас выполняется только при старте
   сервиса — при появлении новых отчётов нужен перезапуск контейнера:
   ```
   docker compose restart web
   ```

## API

- `GET /api/reports` — список отчётов в JSON
- `GET /api/reports/{id}` — метаданные + сырой XML отчёта

## Отличия от Python-версии

- Нет автогенерируемой документации (Swagger) — в Go для этого
  нужна отдельная библиотека, здесь не подключена
- Пересканирование отчётов без пересборки/перезапуска контейнера
  пока не вынесено в отдельную команду (было `docker compose exec
  web python scan_reports.py`) — в Go-версии сканирование зашито в
  старт сервиса

## Известные ограничения текущей версии

- Тип отчёта определяется по названию подпапки в `reports/`
- Нет валидации XML по XSD-схеме
- Нет аутентификации доступа к веб-интерфейсу и API
