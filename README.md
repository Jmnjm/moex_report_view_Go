# MOEX Report Viewer

Сервис для просмотра XML-отчётов Московской биржи: человекочитаемый
веб-интерфейс + REST API для других сервисов.

## Архитектура

Не парсим содержимое отчётов — используем готовую связку XML +
XSLT-стиль от биржи, преобразование делается на сервере (lxml).
Стиль для конкретного отчёта определяется из самого файла
(инструкция `<?xml-stylesheet ... ?>`) и кэшируется локально после
первого скачивания. PostgreSQL используется как реестр метаданных
(тип отчёта, путь к файлу, путь к стилю) — не для хранения самих
данных отчётов.

## Структура проекта

- `db.py` — работа с реестром отчётов в PostgreSQL
- `scan_reports.py` — сканирует reports/, определяет и кэширует стиль для новых файлов
- `xslt_resolver.py` — извлекает ссылку на стиль из XML, скачивает и кэширует
- `transform.py` — XML + XSLT → готовый HTML
- `main.py` — веб-сервер (FastAPI): страницы для людей + JSON API

## Запуск

1. Положить XML-отчёты в `reports/<тип_рынка>/`, например `reports/Currency/`.
2. Поднять сервис:
   ```
   docker compose up --build
   ```
3. Открыть `http://localhost:8000/` — список отчётов.
4. При появлении новых файлов пересканировать:
   ```
   docker compose exec web python scan_reports.py
   ```

## API

- `GET /api/reports` — список отчётов в JSON
- `GET /api/reports/{id}` — метаданные + сырой XML отчёта
- `GET /docs` — автогенерируемая документация (Swagger)

## Известные ограничения текущей версии

- Тип отчёта определяется по названию подпапки в `reports/`
- Нет валидации XML по XSD-схеме
- Нет аутентификации доступа к веб-интерфейсу и API
